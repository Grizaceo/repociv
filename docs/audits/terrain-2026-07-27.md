## Audit gist

RepoCiv is "a single-user alpha dashboard that visualizes a workspace
of repos as cities on a hexagonal Civilization V-style map, agents as
animated units, sub-processes as buildings inside each city; renders
in Canvas 2D + WebGL/Three.js (r175); ships as Vite SPA + Python
HTTP bridge + DuckDB ledger; MIT; intent-frozen scope."

Three thesis commitments:

  1. The visualization IS the product — it is not a wrapper around an
     orchestrator.
  2. Single-user alpha, opinionated, scope frozen until dogfooding
     says otherwise.
  3. Compatible with the user's existing Hermes Agent fleet via
     upstream MCP server (server/mcp_server.py).

This audit collects evidence against each commitment.

## Repositioning statement (lock this in)

RepoCiv owns the **execution-mode** of the "millennial gamers were
pre-trained" thesis: workspace-as-civilization, agents-as-cities,
hex-grid 4X-style top-down strategy with biomes and unit growth.
AgentCraft owns the **tactical-mode**: RTS-style control of many
agents, race-themed, hook-driven. Same human thesis, different
cognitive load. Consolidation is unlikely because the metaphors
exhaust each other only when both products succeed.

If you are tempted in late 2026 to "ship the same RTS interface",
re-read this paragraph. Don't.
